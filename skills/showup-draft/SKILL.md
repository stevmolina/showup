# Show Up draft

Turn one grounded moment into copy that sounds like Steven.

Read [Steven's social voice](../../references/voice.md). When the source needs verification or more evidence, also read [work sources and safety](../../references/sources.md).

## Workflow

1. Find the human point before choosing a format. Identify the recognizable situation, tension, decision, result, or unresolved question.
2. Check that every factual claim is supported by the supplied material or linked evidence. Mark inference and uncertainty plainly.
3. Choose the platform shape. Use X when compression helps. Use LinkedIn when context earns its space.
4. Draft one strong version per requested platform. Offer variants only when Steven asks or when two approaches represent a real choice.
5. Cut creator language and unnecessary explanation. Let screenshots, clips, repositories, and demos carry technical detail when possible.

Search current discussion only when Steven requests trend research or when a time-sensitive claim needs verification. Cite the sources used.

## Boundaries

- A thin idea stays a seed. Ask for the missing real moment instead of manufacturing a story.
- Drafting returns copy in chat. Save it to Notion or Typefully only when Steven requests that write.
- Plane and client work follow the private-material rules in the source reference.

## Done

The draft is complete when it has one clear human point, sounds consistent with Steven's voice, fits the chosen platform, and contains only supportable claims.
