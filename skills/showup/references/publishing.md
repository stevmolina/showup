# Publishing

Use this reference when creating or managing Typefully drafts, adapting content to a platform, scheduling, publishing, or interacting with social accounts.

## Platform fit

Use X for a compressed observation, sharp opinion, short build update, or conversation prompt. Use LinkedIn when the useful part needs more context, a narrative, or an explanation of a decision. Adapt the same story to each platform instead of copying identical text.

Apply [Steven's voice](steven-voice.md) before saving any draft.

## Typefully workflow

1. Discover the connected Typefully social sets and identify the intended account by stable ID.
2. If timing matters, inspect the queue and timezone before proposing or changing a schedule.
3. Create platform-specific content and save it as a draft by default.
4. Verify the returned draft ID and private URL. Fetch the draft or draft list when later state matters.
5. Schedule or publish only when Steven has explicitly authorized the exact content, account, and timing.

Discover the live tool schema before each mutation. Tool fields and connected platforms can change. Do not infer that a social set contains both X and LinkedIn.

## Review presentation

When drafts are still being explored, provide at most three meaningfully different options. Explain the distinction in one short line, then show the copy without commentary inside it.

When saving a draft, report the platform, account, status, and private review URL. When publishing or scheduling, verify the final state and return the public or scheduled-item URL.

## Side effects

A request to draft permits drafting. A request to save to Typefully permits creating a private draft. Publishing, scheduling, replying, liking, reposting, deleting, following, and sending DMs require explicit authorization for that action.
